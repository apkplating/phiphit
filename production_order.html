📥 รายการรอชุบจาก BL Stock
ดึงยอด "รับเข้าแล้ว แต่ยังไม่ได้ชุบ" จาก bl_stock.html มาให้ดู แยกเป็นรายล็อต/รายบิล (1 หมายเลขชิ้นงานอาจมีหลายบิลหลายแถว) เรียงจากล็อตเก่าสุดก่อน (FIFO) — แสดงเฉพาะล็อตที่ค้างมาแล้ว ≥ 3 วัน (ไฮไลต์สีแดงเตือนให้เห็นชัด) ล็อตที่เพิ่งรับเข้ายังไม่ถึง 3 วันจะยังไม่โชว์ในตารางนี้
ระบบไม่ดันเข้าคิวให้อัตโนมัติ — กดปุ่ม "➕ เข้าคิว" เองทีละแถว/ทีละบิล พร้อมเลือกสายผลิตก่อนยืนยัน จะออกใบสั่งผลิต (PO) ให้ทันที ไปโชว์ที่ตาราง "📜 ใบสั่งผลิตทั้งหมด" ด้านบนเลย ไม่ต้องรอจัดคิว ตัดที่บิลได้ ไม่ปนกับบิลอื่น — ถ้าชุบไม่ครบยอด ส่วนที่เหลือจะกลับมาโชว์ในตารางนี้เองอัตโนมัติตอนกด "🔄 ดึงข้อมูลจาก BL Stock" ครั้งถัดไป
วันที่รับเข้าเลขบิลลูกค้าหมายเลขชิ้นงาน ชื่อชิ้นงานค้างชุบค้างมาแล้วสาย + เข้าคิว
กด "ดึงข้อมูลจาก BL Stock" เพื่อโหลดรายการ
🗂️ คิวรอผลิต (Backlog) — FIFO
ระบบออกใบสั่งผลิตให้อัตโนมัติทุกวัน 05:00 น. ผ่าน GitHub Actions (ไม่ต้องเปิดหน้านี้เลย) — เรียงตามลำดับเข้าคิวก่อนหลัง (FIFO) โดยรวมแล้วต้องไม่เกิน "กำลังการผลิตสูงสุดที่เคยทำได้" ของแต่ละสาย (คำนวณจากยอดผลิตจริงสูงสุดในอดีต)
หน้านี้จะรันซ้ำให้เองอีกครั้งเป็น fallback ตอนเปิดหน้า (เฉพาะสายที่ยังไม่ถูกรันในวันนั้น) เผื่อ GitHub Actions รันไม่สำเร็จ
รายการในคิวนี้มาจากการกด "➕ เข้าคิว" ในตาราง "รายการรอชุบจาก BL Stock" ด้านบนเท่านั้น
ลำดับวันที่เข้าคิวลูกค้าหมายเลขชิ้นงาน ชื่อชิ้นงานเลขบิลสายจำนวน
